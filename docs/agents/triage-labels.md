# Triage 标签

各技能以五个规范 triage 角色表述。本文件将这些角色映射到本仓库 issue 追踪器中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们追踪器中的标签 | 含义                           |
| -------------------------- | ------------------ | ------------------------------ |
| `needs-triage`             | `needs-triage`      | 维护者需要评估此 issue         |
| `needs-info`               | `needs-info`        | 等待报告者补充信息             |
| `ready-for-agent`          | `ready-for-agent`   | 规格完整，可交给 AFK agent     |
| `ready-for-human`          | `ready-for-human`   | 需要人工实现                   |
| `wontfix`                  | `wontfix`           | 不予处理                       |

技能提及某角色时（如「打上 AFK 就绪的 triage 标签」），使用本表中对应的标签字符串。

若实际使用的词汇不同，编辑「我们追踪器中的标签」列即可。
