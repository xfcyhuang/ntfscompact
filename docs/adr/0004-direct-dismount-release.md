# 占用处理直接卷卸载

文件被占用时不再走逐级升级链（Oplock 协商、Restart Manager 优雅关、RM 强制关、句柄强关——0003 全部废弃），直接对目标文件所在卷执行 FSCTL_DISMOUNT_VOLUME 使全卷句柄失效，随后重试压缩/解压。理由：升级链实现复杂、逐级试探耗时且多数场景最终仍要落到强手段；卷卸载一步到位，系统随后在下次访问时自动重新挂载。代价与边界：卷级影响波及全卷所有打开句柄（含无关进程），故要求管理员权限；非管理员或卸载失败时该文件计跳过并报告原因；不设交互确认，卸载失败绝不重试第二次。本 ADR 取代 0003（其风险闸门、退避重试、释放级别开关随之全部移除）。
